---
titel: Pasta pesto met kip
porties: 4
tijd: 25
tags: [pasta, snel]
ingredienten:
  - { hoeveelheid: 400, eenheid: g, naam: penne, afdeling: houdbaar }
  - { hoeveelheid: 300, eenheid: g, naam: kipfilet, afdeling: vlees }
  - { hoeveelheid: 1, eenheid: potje, naam: groene pesto (190 g), afdeling: houdbaar }
  - { hoeveelheid: 250, eenheid: g, naam: cherrytomaten, afdeling: groente }
  - { hoeveelheid: 75, eenheid: g, naam: rucola, afdeling: groente }
  - { hoeveelheid: 50, eenheid: g, naam: Parmezaanse kaas, afdeling: zuivel }
  - { hoeveelheid: 30, eenheid: g, naam: pijnboompitten, afdeling: houdbaar }
  - { naam: olijfolie, afdeling: houdbaar }
  - { naam: zout en peper }
---

1. Kook de penne volgens de verpakking.
2. Rooster de pijnboompitten kort in een droge koekenpan en zet ze apart.
3. Snijd de kip in blokjes, bestrooi met zout en peper en bak ze in een scheut olijfolie gaar.
4. Halveer de cherrytomaten.
5. Giet de pasta af en meng hem met de pesto, de kip en de tomaten.
6. Schep de rucola erdoor en maak af met geraspte Parmezaanse kaas en de pijnboompitten.
