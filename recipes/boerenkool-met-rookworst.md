---
titel: Boerenkoolstamppot met rookworst
porties: 2
tijd: 35
tags: [stamppot, hollands, winter]
ingredienten:
  - { hoeveelheid: 750, eenheid: g, naam: kruimige aardappelen, afdeling: groente }
  - { hoeveelheid: 400, eenheid: g, naam: boerenkool (gesneden), afdeling: groente }
  - { hoeveelheid: 1, naam: ui, afdeling: groente }
  - { hoeveelheid: 1, naam: rookworst, afdeling: vlees }
  - { hoeveelheid: 100, eenheid: ml, naam: melk, afdeling: zuivel }
  - { hoeveelheid: 1, eenheid: el, naam: mosterd, afdeling: houdbaar }
  - { hoeveelheid: 1, eenheid: zakje, naam: jus, afdeling: houdbaar }
  - { naam: zout en peper }
---

1. Schil de aardappelen en snijd ze in gelijke stukken. Snipper de ui.
2. Zet de aardappelen net onder water met een snuf zout op en breng aan de kook.
3. Leg de boerenkool en de ui bovenop de aardappelen, doe de deksel erop en kook alles samen in
   **20 minuten** gaar (de kool stoomt mee).
4. Verwarm tegelijk de rookworst **20 minuten** in een pan met heet water, net tegen de kook aan
   (niet laten koken, anders springt hij open).
5. Maak de jus volgens het zakje (ongeveer 5 minuten).
6. Verwarm de melk. Giet de aardappelen en kool goed af en stamp ze fijn met de warme melk en de
   mosterd. Breng op smaak met zout en peper.
7. Snijd de rookworst in plakken en serveer met een kuiltje jus in de stamppot.
